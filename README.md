# Magnit Basket

Скилл для проверки продуктовой корзины в Магните по адресу: наличие, цены и
предварительный итог. Работает в ИИ-агентах, которые умеют запускать локальные
Python-скрипты, например Codex, Claude Code и Cursor.

Нужен **Python 3.10+** и доступ к интернету. Дополнительные Python-пакеты,
аккаунт Магнита и API-ключи не требуются.

## Автоматическая установка

Скопируйте этот промпт в своего ИИ-агента:

```text
Установи мне скилл magnit-basket из репозитория:
https://github.com/howleysens/magnit-basket

1. Склонируй репозиторий во временный каталог.
2. Определи каталог пользовательских скиллов своего клиента.
   Для Codex используй ~/.agents/skills, для Claude Code — ~/.claude/skills.
   Для другого клиента сначала проверь, где он читает скиллы.
3. Скопируй туда весь каталог skills/magnit-basket, включая SKILL.md
   и scripts/magnit_basket.py. Установи для пользователя, а не для одного проекта.
   Если magnit-basket уже установлен, обнови только его. Другие скиллы не меняй.
4. Проверь, что установленный скрипт запускается:
   python3 <каталог-скиллов>/magnit-basket/scripts/magnit_basket.py --help
5. Сообщи путь установки и объясни, как вызвать скилл в моём клиенте.

Не используй sudo. Не устанавливай MCP-сервер и дополнительные зависимости:
для скилла достаточно Python и файлов из skills/magnit-basket.
```

После установки начните новый чат или перезапустите клиент, если скилл не появился.

## Установка вручную

Скачайте репозиторий:

```bash
git clone https://github.com/howleysens/magnit-basket.git
cd magnit-basket
```

### Codex

```bash
mkdir -p ~/.agents/skills
cp -R skills/magnit-basket ~/.agents/skills/
```

### Claude Code

```bash
mkdir -p ~/.claude/skills
cp -R skills/magnit-basket ~/.claude/skills/
```

Копируйте **весь каталог** `magnit-basket`: одного `SKILL.md` недостаточно.
Для другого клиента используйте его каталог пользовательских скиллов.

## Как пользоваться

После установки попросите агента:

```text
Используй скилл magnit-basket. Проверь корзину в Магните
по адресу: г. Санкт-Петербург, Гидротехников 5.

Яйца С1 20 штук
Молоко 1 упаковка
Сливки самые жирные
Бекон самый дешевый
```

В клиентах с поддержкой команд скиллов можно вызвать `/magnit-basket`.

Скилл только читает каталог: ничего не покупает и не резервирует.
Адрес отправляется в `photon.komoot.io` для геокодирования, координаты и запросы
товаров — в `magnit.ru`. Итог не включает доставку и условные акции.
