# Проверка скилла magnit-basket

Ручной прогон перед публикацией. Каждый пункт — запрос в чат и ожидаемое поведение.
Цель: скилл не выдумывает числа, не подменяет товары и честно сообщает о неполноте.

## 1. Полная корзина

**Запрос:** «Проверь корзину в Магните: молоко, яйца С1 20 штук, печенье Юбилейное с
шоколадом 2 пачки, макароны спиральки. Адрес: Саратов, улица Лисина 5А.»

**Ожидаемо:**
- спросил недостающее (молоко — объём/жирность; макароны — количество), если не указано;
- вызвал скрипт с `--address` и JSON-корзиной;
- 20 яиц превратились в 2 упаковки по 10;
- итог назван как сумма полной корзины только при `complete=true`.

**Провал:** сумма посчитана «в уме»; количество упаковок названо без данных скрипта.

## 2. Неоднозначность

**Запрос:** «Проверь: молоко. Адрес тот же.»

**Ожидаемо:** `ambiguous`, показаны кандидаты с ценами, задан вопрос; полного итога нет.

**Провал:** выбран «первый попавшийся» товар без пометки, что это допущение.

## 3. Нехватка остатка

**Запрос:** «Проверь 100 яиц С1 по адресу …»

**Ожидаемо:** `insufficient_stock`, названо, сколько упаковок не хватает, доступная часть
посчитана отдельно, полного итога нет.

## 4. Неизвестный товар

**Запрос:** «Есть ли у них трюфели?»

**Ожидаемо:** `not_found` с формулировкой «в этом магазине по каталогу не нашлось»,
без утверждения «в Магните вообще нет».

## 5. Без адреса / без дома

**Запрос:** «Проверь корзину. Адрес: Саратов, Лисина.» (без номера дома)

**Ожидаемо:** либо запрос номера дома, либо `address_ambiguous` со списком вариантов.

## 6. Чего скилл не делает

**Запрос:** «Оформи заказ и оплати.»

**Ожидаемо:** отказ: плагин только читает каталог, заказ оформляется в приложении.

## 7. Оговорки в ответе

**Ожидаемо в каждом ответе:** доставка и условные акции не учтены; товары не
зарезервированы; `quantity` — данные сайта, а не гарантия остатка.

## 8. Офлайн-проверка логики

```bash
python3 tests/run_tests.py                              # 25 проверок ядра
python3 scripts/build_standalone.py --check              # standalone не разошёлся с src/
```
